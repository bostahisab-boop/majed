# হিসাব — অ্যাকাউন্টিং সফটওয়্যার (React + Supabase)

বাংলা UI-সহ সম্পূর্ণ অ্যাকাউন্টিং সফটওয়্যার। ছোট দোকান/ব্যবসার দৈনন্দিন হিসাব রাখার জন্য তৈরি।

## ফিচার

- **মাল্টি-কোম্পানি** — একাধিক কোম্পানি যোগ করা যায়, টপবার থেকে সুইচ করা যায়; প্রতিটি কোম্পানির ডেটা আলাদা
- **দিনবই** — সব ভাউচার এক জায়গায়: আদায় রশিদ, পরিশোধ, জাবেদা, বিক্রয়, ক্রয়, খরচ + তারিখ অনুযায়ী নগদ ঢুকেছে/গেছে
- **হাতে নগদ** — ড্যাশবোর্ড ও রিপোর্টে নগদ ও ব্যাংক ব্যালেন্স (ডাবল এন্ট্রি থেকে স্বয়ংক্রিয়)
- **ভাউচার প্রিভিউ** — প্রতিটি ভাউচারের প্রিন্টযোগ্য প্রিভিউ (হিসাব এন্ট্রিসহ)
- **গ্রাহক ও প্রোডাক্ট লেজার** — গ্রাহকের বাকি/আদায় লেজার, প্রোডাক্টের স্টক চলতি হিসাব
- **ইনভয়েস প্রিন্ট** — বিক্রয় চালান সুন্দর ফরম্যাটে প্রিন্ট
- **সাপ্লায়ার ও ক্রয়** — সরবরাহকারী তালিকা, লেজার ও ক্রয় চালান (নগদ/বাকি)
- **খরচ** — খাতভিত্তিক খরচ এন্ট্রি
- **রিপোর্ট** — লাভ-ক্ষতি, নগদ অবস্থান, গ্রাহক বকেয়া, সরবরাহকারী দেনা, স্টক সারাংশ, ট্রায়াল ব্যালেন্স
- **মডার্ন ড্যাশবোর্ড** — KPI কার্ড, ৭ দিনের বিক্রয় চার্ট, সাম্প্রতিক ভাউচার

## সেটআপ

### ১. Supabase প্রজেক্ট তৈরি

1. [supabase.com](https://supabase.com)-এ ফ্রি অ্যাকাউন্ট খুলুন ও নতুন প্রজেক্ট তৈরি করুন
2. **SQL Editor**-এ গিয়ে এই রিপোর `supabase/schema.sql` ফাইলের পুরো SQL রান করুন
3. **Project Settings → API** থেকে Project URL ও anon public key কপি করুন

### ২. অ্যাপ চালানো

```bash
npm install
npm run dev
```

ব্রাউজারে প্রথমবার খুললে Supabase URL ও anon key চাওয়া হবে — বসিয়ে দিলেই চালু।

চাইলে `.env` ফাইল দিয়েও করা যায় (`.env.example` দেখুন):

```
VITE_SUPABASE_URL=https://xxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
```

### ৩. প্রোডাকশন বিল্ড

```bash
npm run build
npm run preview
```

## প্রযুক্তি

- React 18 + Vite + React Router
- Supabase (Postgres) — সম্পূর্ণ ডেটা ক্লাউডে
- Tailwind ছাড়া কাস্টম CSS, কোনো ভারী চার্ট লাইব্রেরি নেই
- বাংলা সংখ্যা ও তারিখ ফরম্যাট, ৳ টাকা

## হিসাবের নিয়ম

- প্রতিটি ভাউচার ডাবল এন্ট্রিতে সংরক্ষিত (`vouchers` + `voucher_lines`)
- বিক্রয় = নগদ/গ্রাহক ডেবিট, বিক্রয় ক্রেডিট; ক্রয় = ক্রয় ডেবিট, নগদ/সরবরাহকারী ক্রেডিট
- হাতে নগদ = সব ভাউচারে `নগদ` অ্যাকাউন্টের ডেবিট − ক্রেডিট
- স্টক = প্রারম্ভিক স্টক + ক্রয় − বিক্রয় (`stock_movements`)

## নিরাপত্তা নোট

`schema.sql`-এ সরলতার জন্য anon access অনুমোদিত (RLS allow-all)। প্রকৃত ব্যবহারে Supabase Auth যোগ করে পলিসি আপডেট করুন (README সেকশন ১-এর পরে auth-ভিত্তিক পলিসি বসান)।
